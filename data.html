Here is how I clean and analyse data

First step, get the dataset

I got my data from the National Statistics website. This is data on youth victims by offense type. Before downloading it, I first checked that the dataset was in the right format and also its publication date. Then I started to clean and analyse my dataset using Python and the pandas libraries. 

# Import the dataset
import pandas as pd

df = pd.read_csv("youth_victims.csv")
df.head(10)
# drop the columns that I don't need
df = df.drop(columns=['Offense Category (%)', 'Percentage of Total Victims'])
# after making sure that "-" means no value, change "-" to 0
df = df.replace("-", 0)
df
#Check the data types of each column
df.dtypes
df["Male"] = df["Male"].astype(int)
df["Female"] = df["Female"].astype(int)
df["Change in Number"] = df["Change in Number"].astype(int)
df["Growth Rate (%)"] = df["Growth Rate (%)"].astype(float)
df.dtypes
# Save the cleaned dataset
df.to_csv('youth1.csv',encoding='utf-8')
Focus on the part I want to futhrer research and report on

Eventually, I would separate the data for male and female victims, and create two charts to compare the two groups. Since the total number isn’t exactly the same between males and females, I first transferred the number to percentage, and deleted the total row. 


# Create a copy of the dataFrame
youth2 = df.copy()
male_total = youth2.loc[0, "Male"]      
female_total = youth2.loc[0, "Female"] 
# Divide the male and female values by their respective total values
youth2["Male"] = youth2["Male"] / male_total
youth2["Female"] = youth2["Female"] / female_total
# Delete the total row
youth2 = youth2.drop(index=0).reset_index(drop=True)
#Change the unit to %
youth2["Male"] = (youth2["Male"] * 100).round(2)
youth2["Female"] = (youth2["Female"] * 100).round(2)
youth2

From what I observed, the distribution of offense types among female victims was more scattered than that among male victims. There were also a few interesting findings. First, fraud was the most common offense type for both male and female victims. Second, sexual-related offense types appeared much more frequently among female victims

Since there were 21 different offense types, the dataframe was quite large and difficult to read. At the same time, I noticed that some offense types accounted for only a very small share of cases, with percentages below or around 1%. Therefore, I would first focus on the main offense types and remove those with very small percentages from both the male and female datasets.

To make the comparison between female and male victims clearer, I split the dataset into two separate datasets, named Female and Male, respectively.


# create a new male only dataFrame
youth2male = youth2.copy()
youth2male = youth2male.drop(columns=["Female"])
youth2male = youth2male[youth2male["Male"] >= 0.89]
youth2male = youth2male.reset_index(drop=True)

#Create a new female only dataframe
youth2female = youth2.copy()
youth2female = youth2female.drop(columns=["Male"])
youth2female = youth2female[youth2female["Female"] >= 0.92]
youth2female = youth2female.reset_index(drop=True)

#Save the dataframes as CSV files
youth2male.to_csv('youthmale.csv', encoding='utf8')
youth2female.to_csv('youthfemale.csv', encoding='utf8')
